# FinTech UniVerse 1.0 — Frontend (MVP, Sprint 2)

React + Vite + Tailwind. Реалізовано сторінки **/register**, **/login**, **/cabinet** з базовою валідацією, зберіганням JWT та інтеграцією з бекендом `https://fintechbackend.online`.

## Швидкий старт


# 1) Встановити залежності
npm i

# 2) Запуск у дев-режимі 
npm run dev

# 3) Прод-збірка
npm run build
npm run preview
